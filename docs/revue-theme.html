Le piège du repli

La variante info n'a aucun jeton défini : son repli est --color-violet-700. C'est la couleur Periscolia retirée du thème, qui reviendrait dès qu'un écran utiliserait cette variante.

L'arbitrage à trancher

Dans la maquette, la marque est violette et le bleu sert d'information : les deux ne se confondent pas. Notre marque étant azur, un info bleu entrerait en collision avec elle.

marque azur info bleu — maquette deux bleus voisins
marque azur info teal — proposé se distinguent

C'est le seul écart assumé avec la maquette. Le teal est déjà la valeur de --info dans theme.oui-crm.css ; il n'était simplement jamais atteint.
